# TicketPulse

TicketPulse is an enterprise-style Help Desk Ticket System where users can submit and track support requests, while support agents and administrators manage, triage, comment on, and resolve tickets through a centralized command center.

## Features

- Role-based access control with distinct permissions for Users, Support Agents, and Administrators
- TicketPulse Command Center operational dashboard with real-time statistics and ticket health scoring
- Support ticket lifecycle management with validated status workflow transitions
- Chronological ticket discussion stream for transparent collaboration
- Immutable audit trail tracking ticket creation, assignments, priority adjustments, and status changes
- Notification system alerting users and agents of assignments, replies, and status updates
- Comprehensive reports and analytics page with multi-dimensional filtering and resolution statistics
- Global search, multi-field filtering, and server-side pagination
- Administrative user management and role assignment

- JWT authentication
- Password hashing
- Backend permission enforcement
- `.env` excluded from Git
- No secrets or credentials stored in repository

## Purpose

TicketPulse demonstrates full-stack development using Angular, Django REST Framework and PostgreSQL, including authentication, CRUD operations, REST APIs, database management, role-based authorization and analytics.
